Connect Dropbox

  1. The Dropbox account that holds the Trizetto Data folder must be the one signed in to dropbox.com in this browser. Then open this Dropbox approval page.
  2. If Dropbox shows a warning that the app is in development, click Continue. Then click Allow. Dropbox shows a code.
  3. Paste the code here and press Get token.
  4. Copy this value. In Vercel add an environment variable named DROPBOX_REFRESH_TOKEN with it, for Production. Then redeploy and press Check again.
    It is shown once. If you lose it, repeat these steps.
